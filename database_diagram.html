La Mia — Firestore Data Dictionary & Security Rules Specification

Field-Level Constraints · Access Control Rules · Denormalization Policies · Composite Index Specifications

A4 Landscape Data Dictionary Security Rules v2
1. Core Content: recipes, comments, ratings Cloud Functions + Security Rules
Collection / Field Type Constraints & Security Rule Authoritative Source
recipes/{id}.status string Server Auth 'pending' | 'approved' | 'rejected' | 'hidden'. Client create forces 'pending'. Cloud Functions (AI Moderation)
recipes/{id}.category string Enforced in rules: ['Almusal', 'Ulam', 'Sabaw', 'Merienda', 'Panghimagas', 'Gulay', 'Inihaw', 'Lamang Dagat', 'Pulutan'] Client Form / Seed Script
recipes/{id}.likeCount int ±1 Only Incremented / decremented via batch write. Bounded to prevent spoofing. Client Batch / Cloud Function
recipes/{id}.ratingAvg / Count double, int Server Auth Computed from transaction over ratings subcollection. ratingAvg ∈ [0.0, 5.0]. Transaction / Cloud Function
recipes/{id}.trendingScore int Server Auth Recalculated hourly via cron function from 7-day velocity. updateTrendingScores (Pub/Sub)
comments/{commentId}.isReply boolean Enforced: isReply == (parentCommentId != null). Arbitrary threading supported. Client (CommentRepository)
ratings/{recipeId}/users/{uid} int Value restricted to 1..5. Enforces strictly 1 rating per user per recipe document. Client (RatingRepository)
Composite Indexes: (1) `category` ASC, `status` ASC, `ratingAvg` DESC; (2) `status` ASC, `trendingScore` DESC; (3) `authorId` ASC, `createdAt` DESC.
2. User Profiles & Social Graph: users, following, likes ±1 Counter Protection
Collection / Field Type Constraints & Security Rule Authoritative Source
users/{uid}.role string Admin Guarded 'user' | 'trusted' | 'admin'. Clients cannot elevate on create or update. AuthService / Admin Console
users/{uid}.recipeCount int Immutable Blocked from client update. Bumper on recipe approval. onRecipeApproved Function
users/{uid}.follower/ingCount int ±1 Only Batched with following/{uid}/users/{targetUid} write. FollowRepository Batch
users/{uid}.totalLikesReceived int ±1 Only Incremented when another user likes author's recipe. LikeRepository Batch
users/{uid}/likes/{recipeId} map Per-user index for profile Likes tab. Mirror written to `likes/{recipeId}/users/{uid}`. LikeRepository Batch
users/{uid}/saved/{recipeId} map Offline-synced recipe bookmarked by user. Mirrors `favorites/{uid}/items/{recipeId}`. FavoritesRepository Batch
Read Visibility: `users/{uid}` profiles are publicly readable to allow chef search, recipe attribution, and followers screen for guest users.
3. Planner & Pantry: users/{uid}/mealPlans, grocery_items Private Subcollections
Collection / Field Type Constraints & Security Rule Lifecycle / Sync Behavior
mealPlans/{weekId}.weekId string Format: `week_YYYY_MM_DD` (deterministic Monday anchor). One document per week. WeeklyMealPlanModel
mealPlans/{weekId}.days map Keyed by ISO date `YYYY-MM-DD`. Contains slots: breakfast, lunch, dinner, snack. Client weekly planner state
days.*.MealPlanItem map Snapshot: {recipeId, recipeName, coverPhotoUrl, servings, prepTime, cookTime, ingredients[]}. Embedded snapshot prevents stale refs
grocery_items/{itemId} document Fields: name (string), checked (bool), recipeId? (FK), recipeName? (string), addedAt (ts). Batch added from recipe ingredients
ingredientCatalog/{nameSlug} document Canonical ingredient pricing catalog. Merged by ingredient name across seed recipes. tools/seed_recipes.js (Admin SDK)
Privacy Guard: `mealPlans` and `grocery_items` can only be read or written by the authenticated owner (`request.auth.uid == userId`).
4. System & Security: notifications, moderationLogs, OTP Cloud Functions Admin SDK
Collection / Field Type Constraints & Security Rule Handler / Policy
notifications/{notifId} document Created by Cloud Functions or signed-in users on social events. Read/update/delete by recipient only. onNotificationCreate (FCM Push)
notifications.type string recipe_like | recipe_comment | comment_like | comment_reply | new_follower | following_new_recipe | recipe_approved | meal_reminder | daily_suggestion. NotificationType enum
moderationLogs/{logId} document Admin Read Only Direct client write forbidden (`allow write: if false`). onRecipeCreate (Gemini + Vision)
otp_verifications/{docId} document Locked to Admin SDK Client direct access completely blocked (`allow read, write: if false`). sendEmailOtp / verifyEmailOtp
otp_verifications.security SHA-256 6-digit code salted and HMAC-hashed. 60-second cooldown per request, 10-minute expiry, max 5 attempts. Resend API Email Dispatcher
reports/{reportId} document Any signed-in user can submit a report. Content exceeding threshold triggers automatic quarantine. onReportThreshold (Cloud Function)
Zero Trust Invariant: Popularity counters, moderation approval, and authentication secrets can never be forged from mobile clients.
Security Invariants: Server-Authoritative Status & Counters Data Validation: Firestore Rules regex & size bounds Auth Protection: Cryptographic HMAC OTP + Firebase Auth
